## Инструкция по запуску и управлению MEPhI_ROS2_drone :skull:


### ШАГ 0: Узнайте ip адрес робота для этого проведите сканирование сети с помощью команды:
```
nmap 192.168.1.0/24
```
Сканирование занимает около 30 секунд после чего будут выведена различная информация о подключенных устройствах, нужно найти комбинации чисел вроде 192.168.0.0 последние два числа могут отличаться.

После чего воспользуйтесь командой 
```
ssh pi@192.168.0.0
```
Введите пароль: `12345`

Вы увидите что имя устройства от лица которого открыть терминал изменился с `grigorisha@grigorisha-911M:~$` на  `pi@pi-desktop:~$` вы можете посмотреть какие директории (папки) есть на микрокомпьютере робота введя команду `ls`

Перемещаться по папкам можно вводя команду `cd имя_папки` в которую вы хотите зайти, чтобы вернуться на один шаг назад введите `cd .. `

В директории `andino_ws` находится все файлы необходимые для функционирования робота.

чтобы посмотреть структуру папок робота можно воспользоваться командой
```
tree ~/andino_ws/src/andino
```

### Шаг 1: Запуск базовых нод

Запустите базовые ноды робота:
```
ros2 launch andino_bringup andino_robot.launch.py
```
Это активирует ноды для работы с двигателями и лидаром.

Проверьте доступные топики:
```
ros2 topic list
```
Ожидаемые топики:

`/odom`: данные одометрии

`/scan`: данные лидара

Проверьте работу лидара путем вывода получаемой информации в терминал командой 
```
ros2 topich echo /scan
```
Запустите `rviz`:
```
rviz2
```
Добейтесь отображения результатов сканирования лидара 


Используйте команду для ручного управления с клавиатуры
```
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

### Шаг 2: Запуск SLAM

Запустите `SLAM`:
```
ros2 launch andino_slam slam_toolbox_online_async.launch.py
```
Запустите `rviz`:
```
rviz2
```
Управляйте роботом для построения карты, для этого в новом терминале запустите телеуправление:
```
ros2 run teleop_twist_keyboard teleop_twist_keyboard 
```
Используйте клавиши (исполнительные клавиши будут отображены на мониторе) для медленного перемещения робота по помещению

### Шаг 3: Сохранение карты

Сохраните созданную карту:
```
ros2 run nav2_map_server map_saver_cli -f ~/andino_ws/map/andino_map.yaml
```
Карта сохранится в файлах `andino_map.pgm` и `andino_map.yaml` в домашней директории

Остановите `SLAM`:

Нажмите `Ctrl+C` в терминале с `SLAM`

### Шаг 4: Повторное использование карты

Запустите навигацию с сохраненной картой:
```
ros2 launch andino_navigation bringup.launch.py map:=~/andino_map.yaml
```
Установите начальную позицию в `RViz`:

Используйте инструмент `2D Pose Estimate` в `RViz`

Щелкните на карте, чтобы указать приблизительное положение робота
